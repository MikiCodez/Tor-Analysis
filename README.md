Tor Browser Vs Standard Browser: Network Traffic Analysis 

Overview:
This project investigates the difference in network traffic between standard browsers like Google compared to more secure browsers like Tor. This is done by analyzing network traffic through Wireshark and comparing their diffrences

Question:
How does Tor browser handle connections differently compared to that of standard browsers, as observed through packet level analysis

Objectives:
- Look at network traffic generated by a standard browser
- Look at network traffic generated by Tor browser
- Investigate DNS behavior, packet transfers and methods of securing meta-data sent between a host and a server

Tools Used:
- Wireshark - Used to observe network traffic
- Tor - Used as the secure browser in this study
- Chrome - Default browser to compare to Tor
- Firefox - Second browser to support research used with Chrome

Process:
To reduce outside variables the process will be done multiple times across the same browser, captures will be saved and analyzed through Wireshark Filters 

Ethical Use:
Sensitive Data will not be published knowingly, and an aim to publish data as polished as possible will be established
